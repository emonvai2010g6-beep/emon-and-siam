# Siam & Emon Friends | FunZone

## ফাইল
- `index.html` — ওয়েবসাইটের মূল পেজ
- `style.css` — ডিজাইন
- `app.js` — কুইজ ও গেমের কোড

## GitHub Pages-এ প্রকাশ
1. GitHub-এ নতুন repository তৈরি করো।
2. এই ZIP-এর তিনটি ফাইল extract করে repository-তে upload করো।
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Pages-এর দেওয়া লিংকে ওয়েবসাইট খুলবে।

নোট: স্কোর ব্রাউজারের localStorage-এ থাকে; সব ব্যবহারকারীর জন্য একসঙ্গে leaderboard নেই। গেমগুলো ব্রাউজারে চলে।
